# Skill Pixel (Frontend)

- Ikuti pola komponen, state, dan pemanggilan API yang sudah dipakai project sebelum menulis yang baru.
- Setiap aksi punya state loading, sukses, kosong, dan error; pesan error berasal dari respons server, bukan teks umum.
- Form: label terhubung ke input, validasi sebelum kirim, tombol tidak bisa ditekan dua kali, dan atribut autocomplete yang benar (username, current-password, organization) supaya pengisian otomatis browser tidak salah kolom.
- Jangan mengubah bentuk request atau respons secara sepihak; kalau kontrak kurang, laporkan.
- Buktikan sebelum menyerahkan: jalankan build, lint, dan tes project yang relevan, lalu tulis perintah dan hasilnya.
- Jangan mengklaim sudah melihat tampilan kalau tidak memegang browser; serahkan ke Echo dengan langkah uji yang jelas.
